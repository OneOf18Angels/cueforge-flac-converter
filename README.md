# FLAC Converter

Скрипт розділяє аудіоальбоми на окремі FLAC-треки за даними з CUE-файлів.

## Вимоги

- Python 3.14 або новіший
- FFmpeg, доступний у `PATH`
- Доступ до source-папки з аудіофайлами та CUE-файлами

## Встановлення

```powershell
py -m pip install -r requirements.txt
```

Перевірити доступність FFmpeg можна командою:

```powershell
ffmpeg -version
```

## Запуск

### CLI

Синтаксис команди:

```powershell
py .\convert.py <source> <dest> [--workers КІЛЬКІСТЬ] [--logs ПАПКА_ЛОГІВ]
```

Параметри потрібно передавати саме в такому порядку:

| Параметр | Що вказати |
| --- | --- |
| `source` | Коренева папка з альбомами, аудіофайлами та CUE-файлами |
| `dest` | Папка, куди записувати готові FLAC-файли |
| `--workers` | Необов'язково: максимальна кількість одночасних потоків |
| `--logs` | Необов'язково: папка для log-файлів |

Приклад:

```powershell
py .\convert.py "X:\complete\A-ha - Full Albums Discography" "Z:\new\songs\A-ha" --workers 4 --logs "D:\FLAC-logs"
```

У цьому прикладі:

- `X:\complete\A-ha - Full Albums Discography` — це `source`;
- `Z:\new\songs\A-ha` — це `dest`;
- `4` — максимум одночасних потоків;
- `D:\FLAC-logs` — папка для log-файлів.

Якщо `source`, `dest` або додаткові параметри не передані, програма використовує останні значення з `config.json`.

Графічний інтерфейс можна запустити окремо:

```powershell
py .\ui.py
```

CLI залишається доступним для автоматизації та запуску без GUI.

У GUI кнопка `Перегляд логів` відкриває журнал запусків. Там можна:

- вибрати окремий log-файл;
- відфільтрувати записи за номером потоку;
- відсортувати записи за часом, рівнем, потоком або повідомленням;
- прокручувати великий журнал.

Нові записи групуються за альбомами автоматично. Для старих log-файлів viewer також намагається відновити групування за послідовністю роботи кожного потоку.

## Збірка EXE

Для створення одного Windows-файлу встановіть PyInstaller:

```powershell
py -m pip install pyinstaller
```

Переконайтеся, що `ffmpeg.exe` доступний у `PATH`, потім виконайте:

```powershell
.\build.ps1
```

Готовий файл буде створено тут:

```text
dist\flac-converter.exe
```

Запуск GUI:

```powershell
.\dist\flac-converter.exe
```

### CLI з EXE

Якщо передати параметри `source` і `dest`, `.exe` працює в консольному режимі без GUI.

Синтаксис:

```powershell
.\dist\flac-converter.exe <source> <dest> [--workers КІЛЬКІСТЬ] [--logs ПАПКА_ЛОГІВ]
```

Приклад:

```powershell
\.\dist\flac-converter.exe "X:\complete\A-ha - Full Albums Discography" "Z:\new\songs\A-ha" --workers 4
```

Тут:

- `X:\complete\A-ha - Full Albums Discography` — `source`;
- `Z:\new\songs\A-ha` — `dest`;
- `--workers 4` — максимум чотири одночасні потоки.

`ffmpeg.exe` вбудовується в EXE автоматично.

## Конфігурація та логи

Поруч із `.exe` можна створити `config.json`. Якщо файлу немає, використовуються значення за замовчуванням:

```json
{
    "workers": 4,
    "source": "",
    "dest": "",
    "logs_dir": "logs"
}
```

Після запуску GUI або CLI останні значення автоматично зберігаються в `config.json`. Поле `logs_dir` може бути відносним шляхом (`logs`, тобто папка поруч із `.exe`) або абсолютним шляхом, наприклад `D:\\FLAC-logs`.

Для кожного запуску створюється окремий детальний лог:

```text
logs\flac-converter_20260921_153045_123456.log
```

У лог потрапляють час події, рівень повідомлення, номер потоку, альбом, трек і повний traceback помилки.

Під час конвертації у FLAC записуються metadata з CUE: назва треку, виконавець, альбом, виконавець альбому та номер треку. Якщо FLAC-файли вже існують, повторний запуск оновлює їх metadata без повторного кодування аудіо.

Папка `dest` створюється автоматично, якщо її ще немає.

## Як працює скрипт

- Рекурсивно знаходить усі папки, що містять `.cue`-файли.
- Для кожного альбому знаходить відповідний аудіофайл.
- Обробляє альбоми паралельно в окремих потоках.
- Дозволяє обмежити кількість потоків параметром `--workers`.
- Показує динамічний progress dashboard для всіх альбомів одночасно.
- Відображає стан альбому (`waiting`, `running`, `done`, `skipped`, `error`) і прогрес окремих треків.
- Додає ідентифікатор потоку до логів.
- Зберігає структуру source-папки у destination.
- Пропускає альбом, якщо всі його FLAC-треки вже існують.
- Замінює недопустимі для Windows символи у назвах файлів.

Наприклад:

```text
source\Albums\Artist\Album\album.cue
    ->
dest\Albums\Artist\Album\Artist - 01 Track.flac
```
